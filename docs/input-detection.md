# 离开防护输入检测

离开防护默认关闭。开启后，两个入口共用 `CodexFeishuBridge/AwayGuardInput.cs`，只在接收到鼠标设备移动报告后计数，屏幕光标坐标变化本身不触发告警。

后台线程同时读取 Raw Input 和低层鼠标事件的注入标记：前者排除直接设置光标位置，后者按事件时间过滤 `SendInput` / `mouse_event` 软件输入。没有直接丢弃设备句柄为零的报告，因为精确式触控板也可能使用这种句柄。

每 500 毫秒统计一次设备净位移；净位移至少为 24 个设备单位才算有效样本。10 秒内至少两个有效样本、且满足告警间隔，才执行告警。每次告警消耗本轮计数；关闭和重新开启防护也会清空旧活动。

告警时会弹出警告窗口并尝试发送通知。只有用户另外开启设置后才拍照或请求连续三次告警自动锁屏。原生版警告图标在 5 秒内点击 5 次，可紧急关闭离开防护。成功锁屏后会关闭后续通知和离开防护。

告警日志记录输入来源、有效样本数、净位移和已过滤的软件事件数。底层监听初始化失败会记入运行日志，不退回坐标轮询。驱动级虚拟鼠标仍可能表现为设备输入；本实现不按 agent 进程是否运行来关闭防护，也不能据此识别人。

## 可选实机探针

下面的命令约需 3 秒，会通过 `SetCursorPos` 和 `SendInput` 移动光标，不点击、不输入按键，并尝试在结束时恢复原位置：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests/Test-AwayGuardInput.ps1 -ProbeSoftwareInput
```

执行前关闭正式托盘中的离开防护，保持鼠标、触控板静止，并确认桌面已解锁。真实设备活动可能正确触发检测；Windows 也可能因输入桌面限制拒绝移动光标，此时只能记为未完成，不能当作通过。

探针自身不启动正式托盘，不调用摄像头、飞书或锁屏。默认回归测试不移动光标。纯逻辑测试通过不代表所有真实设备、触控板、虚拟 HID 或远程桌面环境均已验证。
